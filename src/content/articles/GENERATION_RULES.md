# 記事生成デフォルトルール

このリポジトリの `src/content/articles` に追加する記事を生成する際は、以下のルールを厳守してください。

## 1. 必須アフィリエイト情報
各商品（ランキング内の全アイテム）に対して、必ず以下の3つの情報を記載すること。
- **Amazon**: ASINコード（例: `ASIN: B0...`）
- **楽天**: 商品URL（例: `RAKUTEN: https://item.rakuten.co.jp/...`）
- **Yahoo!ショッピング**: 商品URL（例: `YAHOO: https://store.shopping.yahoo.co.jp/...`）
  - ※Yahoo!はURLが不明な場合は商品名を正確に記載すれば、APIで自動補完されます。

## 2. 記事構成
- **形式**: ランキング形式
- **商品数**: 1記事あたり **5〜10商品** を紹介すること
- **マークダウン構造**:
  - `### 👑 第1位: 商品名` の見出しを使用する
  - `[RATING:4.5]` タグで評価を入れる
  - `:::pro` / `:::con` ボックスでメリット・デメリットを記載する
  - `| 仕様 | 内容 |` の形式でスペック表を入れる
  - `[AMAZON_LINK_HERE]` `[RAKUTEN_LINK_HERE]` プレースホルダーを適切な場所に配置する

## 3. カテゴリと分類
以下の5つのカテゴリから適切なものを1つ選択し、MarkdownのFrontmatterに記載すること。
- **美容・スキンケア**
- **ガジェット**
- **インテリア**
- **生活雑貨**
- **便利グッズ**

## 4. カテゴリ・トピックの自動選定（未指定時）
カテゴリやトピックが指定されていない場合は、以下の基準に基づいて自動的に判断し、記事を生成してください。

### トピックの選定基準
- **最新トレンドの反映**: Googleトレンド、Amazon売れ筋ランキング、楽天ランキング、Yahoo!ショッピングの人気商品を参考にすること。
- **SNSでの話題性**: X、Instagram、TikTokで「バズっている」商品を優先的に取り上げる。
- **季節性・イベント・流行**: 季節の変わり目、記念日、大型セールなどのイベントや、その時の最新の流行を考慮する。

### カテゴリの選定基準（バランスの調整）
- **投稿頻度の平準化**: サイト全体の投稿履歴を確認し、まだ記事が少ないカテゴリを優先的に選択する。
- **循環的な運用**: 「美容・ガジェット・インテリア・生活雑貨・便利グッズ」の5カテゴリが、偏りなくバランスよく回るように考慮すること。
