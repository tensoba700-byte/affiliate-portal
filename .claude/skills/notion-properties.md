# ■ 実行手順（この順番で必ず実行すること）
# ※ 1回の実行で【1記事目】【2記事目】の2記事を必ず作成すること。

---

## 【1記事目】

### Step 1-A：1記事目のタイトルを決める
- ジャンル・性格・モード・深度・視点の組み合わせを自律決定する
- タイトル品質基準を満たすタイトルを1つ生成する（品質チェック必須）
- **公開時間の基本方針：朝**（ただしテーマによって上書き可。後述のルール参照）

### Step 2-A：1記事目の商品を6件選定する
- 全商品がStep 1-Aのタイトルテーマと一致していること
- Amazon・楽天両方で購入可能な商品のみ
- 過去に選定した商品と被らないこと

### Step 2.5-A：【必須】1記事目の商品6件を実在確認する
**絶対に省略不可。** WebSearchまたはWebFetchを使って1件ずつ確認すること。

確認項目：
1. **商品ページが存在するか**（404や検索結果0件は除外）
2. **商品タイトル・メーカーが選定内容と一致するか**
3. **価格が取得できるか**（販売中であることの確認）

確認できなかった場合：即除外し代替を選定。6件全て確認済みになるまでStep 3-Aに進まない。

### Step 3-A：1記事目の6件をNotionに書き込む
環境変数 NOTION_API_KEY（.env.localから読み込む）と NOTION_DATABASE_ID=85119084-42c7-4738-b78d-c62f6a7a49d9 を使って「みっけ！記事管理」データベースに追加する。

各Notionプロパティの対応：
- 商品名（title）：記事用商品名
- 製品番号（rich_text）：メーカー型番
- 記事タイトル（rich_text）：Step 1-Aで決めたタイトル（6件全て同じ値）
- 検索商品名（rich_text）：検索に使う正確なキーワード
- 選定理由（rich_text）：性格＋モード＋深度＋使用した視点＋公開時間の判断理由を簡潔に
- カテゴリ（select）：選定ジャンル ※Notionの選択肢と完全一致させること
  選択肢：ガジェット / 家電 / 日用品 / 食品・飲料 / 美容・健康 / 美容・スキンケア / 本・学習 / その他 / ガジェット・家電 / 美容 / 健康食品 / 生活雑貨 / インテリア / 便利グッズ
- 公開時間（select）：以下のルールで決定すること
  【基本ルール】1記事目は「朝」を基本とする
  【テーマ優先ルール】ただし記事テーマによって以下の通り上書きする：
    朝テーマ → 朝：スキンケア / 時短 / 朝食・コーヒー / 出勤準備 / 運動・ストレッチ
    夜テーマ → 夜：リラックス / 睡眠 / 入浴 / インテリア / キャンドル / 読書
  【判断に迷う場合】基本ルール（1記事目=朝）に従う
  【必須】選定理由欄に「公開時間：朝（理由：〜）」の形式で判断根拠を記載すること
  選択肢：朝 / 夜
- ステータス 1（select）：常に「未処理」
- URL系・価格系・画像列には一切触れないこと

### Step 4-A：1記事目のDiscord報告
```
curl -s -X POST "https://discord.com/api/v10/channels/1496037309500620820/messages" \
  -H "Authorization: Bot $TARO_DISCORD_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "✅ 【1記事目】Notionに6件の商品を追加しました"}'
```

## 【2記事目】
※ 1記事目とは**異なるジャンル・テーマ**を選ぶこと。1記事目で選定した商品は使用不可。

### Step 1-B：2記事目のタイトルを決める
- 1記事目とは異なるジャンル・性格・モードを選択すること
- タイトル品質基準を満たすタイトルを1つ生成する（品質チェック必須）
- **公開時間の基本方針：夜**（ただしテーマによって上書き可）

### Step 2-B：2記事目の商品を6件選定する
- 全商品がStep 1-Bのタイトルテーマと一致していること
- Amazon・楽天両方で購入可能な商品のみ
- 過去に選定した商品・1記事目の商品と被らないこと

### Step 2.5-B：【必須】2記事目の商品6件を実在確認する
Step 2.5-Aと同じ手順で、2記事目の全6件を確認すること。

### Step 3-B：2記事目の6件をNotionに書き込む
Step 3-Aと同じNotionデータベースに追加する。

各Notionプロパティの対応はStep 3-Aと同じ。ただし：
- 記事タイトル：Step 1-Bで決めたタイトル（6件全て同じ値）
- 公開時間：
  【基本ルール】2記事目は「夜」を基本とする
  【テーマ優先ルール】朝テーマなら「朝」に上書き可
  【判断に迷う場合】基本ルール（2記事目=夜）に従う

### Step 4-B：2記事目のDiscord報告
```
curl -s -X POST "https://discord.com/api/v10/channels/1496037309500620820/messages" \
  -H "Authorization: Bot $TARO_DISCORD_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "✅ 【2記事目】Notionに6件の商品を追加しました"}'
```
